# Iker Carmona — CV Website

A single-page CV website created for the Hypermedia project using HTML and CSS.

## User Profile — Persona

**Laura Martínez**, 32, is a fictional recruiter at a software company in Barcelona. She visits my website on a laptop to quickly review my skills, projects, education and work experience. She wants clear navigation, readable information and an easy way to contact me.

## Information Architecture

I chose a single-page structure because the main purpose of this website is to present my CV in a clear and direct way. Visitors can find all the information without opening several pages. The sections appear one after another, and the navigation menu stays visible at the top right while scrolling. Each menu link takes the visitor directly to the relevant section.

The page starts with **Home**, which shows my photograph, name, a brief introduction and my location. It also has two links: **Explore my work**, which leads to Projects, and **Contact me**, which leads to Contact. This gives visitors two quick ways to continue.

Next, **About Me** introduces my interests and studies. **Skills** lists the languages and tools I use. **Projects** follows because it shows examples of what I have worked on. I kept the project descriptions short, without extra images or cards, so the page remains simple. **Experience** presents my previous jobs, while **Education** shows my university degree and expected graduation year. The last section, **Contact**, contains my email and GitHub link.

I numbered the section headings to make the order easy to understand. Overall, the layout moves from general information to more specific details and ends with a way to contact me.

## Visual Design

My starting point was the layout I made in Figma. I wanted a simple portfolio that looks personal but is still easy to read. The website uses a **black background** with **white text** and **bright green (`#64f000`)** for the main elements. Green highlights my name, section titles and important links, while white is used for longer paragraphs. This contrast makes the information stand out without needing extra decoration.

I used **Arial** because it is simple, readable and works well for a CV. My name is the largest text on the page and appears in the upper-right corner. A smaller navigation menu sits directly below it. The header stays fixed as the visitor scrolls, so the different sections are always easy to reach.

The Home section includes my photo with a thick green border, just like in the Figma template. Below it, the introduction uses a larger font than the rest of the paragraphs. Section headings are numbered, written in green and separated by space rather than coloured boxes. The other sections use plain text because I wanted to keep the design consistent with the original idea.

I took inspiration from minimal developer portfolio websites with strong typography and contrasting colours. On narrower screens, the layout adjusts so the text and navigation remain usable.
